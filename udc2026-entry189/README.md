# KOBE OPEN TERRAIN ATLAS
## 人口が減る、世帯は増える。｜神戸市9行政区の比較

神戸市の2025年・2026年9月末の住民基本台帳データを、9行政区単位で比較する閲覧・再利用用データ作品です。人口・総世帯・1人世帯・2人以上世帯の変化を、異なる物差しで読み解くための画面と加工CSVを公開しています。

### 作品を見る・データを使う

- **[公式サイトの比較画面を直接開く](https://atelier-tecnoform.com/udc2026-entry189/)** — 9区比較、並び替え、CSV・出典付きZIPのダウンロードを行うためのURL。
- **[画面HTMLの原本・ダウンロード](./index.html)** — 上記のWebページに接続できない場合は、GitHubでHTMLソースを表示し、ファイルを保存してローカルのブラウザーで開けます。GitHubのソース表示画面自体では、並び替え等のJavaScriptは動作しません。
- **[9区の加工CSV](./KOBE_9_WARDS_2025_2026.csv)** — 9行政区×15項目。元の神戸市CSVそのものではありません。
- **[データ辞書](./KOBE_DATA_DICTIONARY_JP.csv)** — 指標の意味・単位・加工内容。
- **[出典・加工方法・利用範囲](./SOURCE_AND_METHODS_JP.txt)** — 出典、CC BY表示、算出定義と制限事項。CSVの再利用時は必ず一緒に参照してください。

### 読み取れる変化

2025年9月末から2026年9月末にかけて、9区合算の登録人口は **5,576人減**、総世帯は **5,160世帯増**、1人世帯は **8,815世帯増**、2人以上世帯は **3,655世帯減**。増加の「数」と世帯内の「割合」では注目する行政区が異なるため、指標を切り替えて比較します。

### 出典・公開範囲

出典：神戸市「住民基本台帳人口」「世帯人数別の世帯数」（2025年・2026年の各9月末）。原典や加工の詳細は [SOURCE_AND_METHODS_JP.txt](./SOURCE_AND_METHODS_JP.txt) を参照してください。神戸市オープンデータポータル上の対象データセットには **CC BY** の表示があります。元データの提供元は神戸市であり、本作品の再集計・表現は atelier TECNOFORM によるものです。

**この公開フォルダは人口・世帯データのみを対象としています。** 国土地理院の標高値・標高3断面・地点座標は収録していません。行政区集計だけで空き家率、住宅需要、個々の斜面安全性、人口変化の因果は判定できません。
