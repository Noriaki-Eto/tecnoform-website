# TECNOFORM CAD EXPRESS — 注文サイト・自動納品MVP

検証日: 2026-10-26  
ステータス: **本番未公開／実課金なし**

## 何を販売するか
アプリの販売ではなく、スマートフォンでCAD作業を発注し、対象作業ならカード決済→CADデータの自動生成・ダウンロードまで完結するサービス。

提案する独立した販売ページ名 **TECNOFORM CAD EXPRESS**。公式JOURNALは読み物主体のまま、自然な記事リンクで誘導する。会社サイトのトップで価格を前面に出さない。

## 価格案（税込・未承認・未公開）
- 定型3D・2D概念作図：980円/件。寸法4項目→3DM/DXF/STL/CSV/PNG
- DXF図面データチェック：490円/件。レイヤー・図形の数をCSV化。原図変更なし
- JWW/JWCの個別編集：無料事前受付・確認後に見積もり。**自動修正は未対応**
- 月額5件：2,980円/月案。**認証・件数管理・継続決済は未実装**

## 実装済み（会話内でMVPソース作成）
FastAPI / HTML-CSS-JS / SQLite（永続領域前提） / Stripe Checkout API / HMAC署名Webhook / 出力ワーカー / 受付状況ページ / 注文専用トークン / 運営者限定JWW原本アクセス。

ローカルのテスト9件成功。実Stripe決済は模擬イベント、開通未実施。デモ版に本番顧客ファイルを投入してはいけない。
