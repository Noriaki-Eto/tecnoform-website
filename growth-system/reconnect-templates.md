# 再接点メール下書き（江藤さんが個人の言葉で調整のうえ送信してください）

これはAIが直接送信するものではありません。`data/relationships.json` の優先度high先に対し、
江藤さん自身の言葉に直して送るための「たたき台」です。事実関係（案件名・年）以外は仮の文面なので、
関係性の温度に合わせて書き換えてください。

## テンプレートA：長期・休眠気味の関係先向け（例：プレナス様）

```
件名：【ご無沙汰しております】atelier TECNOFORM 江藤より

◯◯様

大変ご無沙汰しております。atelier TECNOFORMの江藤です。
◯◯様には〇〇年より大変お世話になり、改めて御礼申し上げます。

その後もガラスアート・和紙照明の制作を続けており、直近では
ヒルトン沖縄宮古島（HBA様）、大丸神戸店（cmyk様）などの実績が加わりました。
サイトの実績ページにも掲載しております：https://atelier-tecnoform.com/#works

もし今後、空間や什器のリニューアル・新規プロジェクトなどでご相談の機会がございましたら、
ぜひお声がけいただけますと幸いです。

引き続きどうぞよろしくお願いいたします。

atelier TECNOFORM
江藤徳晃
info@atelier-tecnoform.com / 078-821-7551
```

## 使い方

1. `data/relationships.json` の `relationship_strength: "high"` の先から着手する。
2. 送ったら `last_touchpoint` に実際の送信日を記入する（`data/relationships.json` を直接編集）。
3. 返信があった／案件化した場合は `data/inquiries-ledger.csv` にも1行追加する。
